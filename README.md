# ✏️ 자기소개 페이지 템플릿 · 별빛노트

**Git + Vercel 첫걸음** 실습 과제용 템플릿이에요.
4단계면 내 페이지가 완성돼요!

## ① 복사하기
오른쪽 위 초록색 **Use this template → Create a new repository**
→ 저장소 이름 `my-profile` → **Public** → Create repository

## ② 형광펜 채우기
내 저장소에서 `index.html` → ✏️ 연필 클릭
→ **Ctrl + F** 로 `mark` 검색 → `<mark>`와 `</mark>` 사이의 글자만 내 내용으로 바꾸기

```html
<mark>내 이름</mark>   →   <mark>홍길동</mark>
```

> ⚠️ `< >` 로 된 태그는 지우지 마세요.
> 다 채웠으면 `<body class="editing">` 을 `<body>` 로 바꾸면 노란 형광펜이 사라져요.

## ④ Commit → Vercel
**Commit changes** → [vercel.com](https://vercel.com) → **Add New… → Project**
→ `my-profile` 옆 **Import** → **Deploy** → 휴대폰으로 확인 🎉

> 🔍 저장소가 안 보이면 Import 화면의 **Configure GitHub App**에서 접근을 허용해요.
